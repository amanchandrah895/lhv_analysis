# figures/

This folder contains all publication-quality figures generated by the experiment pipeline. Every figure is saved at **300 DPI** as a PNG file and is referenced directly in the IEEE conference paper LaTeX source.

All figures are generated by `NB3_Analysis.ipynb` (sections [3.8] and the supplementary figure-generation cell). The filenames match the `\includegraphics{}` calls in the LaTeX source exactly — upload this folder's contents to your Overleaf project root to compile the paper without modification.

---

## Figure Index

### fig1_category_bds1.png
**BDS-1 by Prompt Category — Both Models (Grouped Bar, 95% CI)**

A side-by-side grouped bar chart showing mean BDS-1 for EN-HI and EN-FR language pairs across the three prompt categories (Factual, Normative, Safety), displayed separately for each model. Error bars represent 95% confidence intervals. Value labels are printed on each bar.

- **Key finding:** For Llama-3.3-70B, Safety prompts consistently produce the highest BDS-1 (EN-HI: 0.251, EN-FR: 0.277). GPT-OSS-20B shows higher and more variable divergence across all categories.
- **Paper reference:** Figure 1 (Section IV-A, Descriptive Statistics)

---

### fig2_prompt_heatmap.png
**Per-Prompt BDS-1 Heatmap (All 30 Prompts × 4 Columns)**

A heatmap with all 30 prompts as rows and four model×language-pair combinations as columns (`EN-HI Llama`, `EN-FR Llama`, `EN-HI GPT-OSS`, `EN-FR GPT-OSS`). Cell values are annotated. Colormap is `RdYlGn_r` (green = low divergence, red = high). Row labels are colour-coded by category: green = Factual, orange = Normative, red = Safety.

- **Key finding:** Divergence is heterogeneous within categories. Several Safety (S02, S08, S10) and Normative (N02, N06, N09) prompts are outliers with BDS-1 > 0.50 under GPT-OSS-20B.
- **Paper reference:** Figure 2 (Section IV-A)

---

### fig3_sentiment_divergence.png
**Sentiment Divergence (S_sent) by Category — Boxplot + Stripplot**

A grouped boxplot with individual data points overlaid, showing the distribution of S_sent (absolute sentiment score difference between English and target language responses) broken down by prompt category and language pair.

- **Key finding:** Normative prompts show the highest and most variable sentiment divergence (mean EN-HI: 0.276, EN-FR: 0.286). Factual prompts are lowest (mean EN-HI: 0.083).
- **Paper reference:** Figure 3 (Section IV-F, Sentiment Divergence)

---

### fig4_refusal_distribution.png
**Refusal Class Distribution — Stacked Bar by Category × Language**

A stacked horizontal bar chart showing the proportion of Class 0 (Full Answer), Class 1 (Partial), and Class 2 (Explicit Refusal) responses for each Category × Language combination (9 groups: 3 categories × 3 languages). Percentage labels are printed inside each stack segment. Category boundaries are marked with dashed vertical lines.

- **Key finding:** All Factual responses are Class 0 across all languages. Normative prompts show 30% EN-HI refusal mismatch and 25% EN-FR mismatch. Hindi Safety responses are counter-intuitively *more* compliant (60% Class 0) than English (55%).
- **Paper reference:** Figure 4 (Section IV-E, Refusal Behaviour)

---

### fig5_variance_baseline.png
**Cross-Language Divergence vs. Intra-Language Noise Floor**

A grouped bar chart comparing three values per category: the intra-English variance baseline (grey), mean EN-HI BDS-1 (red), and mean EN-FR BDS-1 (blue). A horizontal dotted line marks the average noise floor. Ratio annotations (e.g., "2.4×") above each bar show how much the cross-language divergence exceeds the noise floor.

- **Key finding:** Cross-language divergence is 2.5× the noise floor for Safety prompts, 2.4× for Factual, and 1.1× for Normative (where intra-English variance is itself higher due to the open-ended nature of ethical questions).
- **Paper reference:** Figure 5 (Section IV-D, Variance Baseline)

---

### fig6_model_consistency.png
**Model Consistency Scatter — Llama-3.3-70B vs. GPT-OSS-20B**

A two-panel scatter plot (one for EN-HI, one for EN-FR) where each point is one prompt, x-axis is Llama BDS-1, y-axis is GPT-OSS-20B BDS-1, and color encodes category. A least-squares regression line is plotted with the Pearson r annotated. The perfect-agreement diagonal is shown as a dotted line.

- **Key finding:** Pearson r = −0.126 (EN-HI) and −0.102 (EN-FR), both non-significant. The near-zero and negative correlation indicates the two models diverge on *different* prompts — divergence is a model-prompt interaction, not a universal prompt property.
- **Paper reference:** Figure 6 (Section IV-C, H3)

---

### fig7_bds1_vs_bdsfull.png
**BDS-1 vs. BDS-full Comparison by Category**

A two-panel grouped bar chart (one panel per language pair) showing BDS-1 (semantic only) alongside BDS-full (composite = 0.5×BDS-1 + 0.3×S_sent + 0.2×S_ref) for each category. Shows how adding sentiment and refusal components shifts the divergence picture.

- **Key finding:** Adding sentiment and refusal to the score most significantly raises Normative divergence (BDS-full EN-HI: 0.256 vs. BDS-1: 0.239), reflecting the high affective shift in ethical responses.
- **Paper reference:** Figure 7 (Section IV-F, Composite BDS-full)

---

### fig8_sentiment_polarity.png
**Sentiment Polarity Shift Across Languages per Category**

A grouped bar chart showing mean compound sentiment scores (from XLM-RoBERTa) per language (English grey, Hindi red, French blue) for each prompt category. The y-axis spans −0.5 to +0.65. A horizontal zero-line separates positive and negative polarity. Background shading indicates sentiment direction.

- **Key finding:** For Normative prompts, both Hindi and French responses are systematically *more positive* than English responses, suggesting culturally modulated tone softening — the models frame ethical questions more agreeably in non-English languages.
- **Paper reference:** Figure 8 (Section IV-F)

## Usage in LaTeX (Overleaf)

Upload all PNG files to the **root** of your Overleaf project. The LaTeX paper references them as:

```latex
\includegraphics[width=\columnwidth]{fig1_category_bds1.png}
\includegraphics[width=\columnwidth]{fig2_prompt_heatmap.png}
% ... and so on
```

No subdirectory path is needed. If you place them in a subfolder (e.g., `figures/`), update the LaTeX preamble with:
```latex
\graphicspath{{figures/}}
```
